# Food Delivery Data Analytics and Performance Insights

## 📌 Overview
An end-to-end data analytics project focused on food delivery sales, customer behavior, delivery performance, and order trends.

## 🎯 Objectives
- Analyze sales and order performance
- Understand customer behavior
- Evaluate delivery performance
- Identify important trends and insights

## 🔄 Workflow
**Dataset → Data Cleaning → Data Preprocessing → Data Analysis → Processed Dataset → Dashboard → Insights**

## 📊 Analysis
- Sales & Revenue Analysis
- Customer Insights
- Delivery Performance
- Payment Method Analysis
- Restaurant Category Analysis
- Time & Order Trends

## 🖥️ Dashboard
The dashboard contains four sections:
- Sales Overview
- Customer Insights
- Delivery Performance
- Time Analysis & Trends

## 🛠️ Tools
- Python
- Pandas
- Google Colab
- Power BI

## 📂 Project Structure
- `Dataset/` – Original dataset
- `Python/` – Data cleaning and analysis notebook
- `Processed_Data/` – Final processed dataset
- `PowerBI/` – Dashboard file
- `Dashboard/` – Dashboard screenshots

## 💡 Key Outcome
The project transforms raw food delivery data into meaningful business insights by combining data preparation, analysis, and interactive visualization.

## 👨‍💻 Project Type
